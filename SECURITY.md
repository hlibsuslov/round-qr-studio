# Security policy

## Supported version

Security fixes are applied to the latest version on the `main` branch.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use the repository's [private vulnerability reporting](https://github.com/hlibsuslov/round-qr-studio/security/advisories/new) instead.

Include a clear description, reproduction steps, affected browsers or environments, and the potential impact. You should receive an acknowledgement within seven days.

Do not include real credentials, private QR payloads, or personal information in a report.
